# Professional Cardano Stake Pool Setup

Blockiy provides a professional Cardano stake pool setup service for operators who want secure, production-ready infrastructure and practical guidance from deployment to handover.

This is a paid professional service. It is not a free tool or an open-source pool implementation.

* Block producer and relay-node configuration
* Firewall, networking, and P2P configuration
* Service management and automatic restart configuration
* Backup planning and recovery guidance
* Pool registration guidance
* KES operational guidance
* Basic operational health checks
* Mithril-ready infrastructure preparation
* One year of technical support for the deployed infrastructure

## Security First

The pool operator remains the sole owner of all wallets, pool keys, server accounts, and rewards.

Blockiy never requests, receives, or stores wallet seed phrases, private signing keys, encrypted key files, server passwords, or other private credentials. Read the complete [Security Policy](SECURITY.md) before starting the service.

## Important Notice

A professionally configured pool does not guarantee block production, delegation growth, staking rewards, uninterrupted third-party hosting, or protection from future Cardano protocol changes. Pool operation remains the responsibility of the operator.
